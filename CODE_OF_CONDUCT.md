# Code of Conduct

## The short version

Be decent. Argue with the code, the data or the reasoning — never with the person.

## Expected behaviour

- Assume good faith. Most disagreements here are about measurement, and measurement
  is genuinely hard.
- Bring evidence. "This score is wrong" is a start; "this score is wrong, here is a
  session where it disagrees with what actually happened" is a contribution.
- Accept that "no" is a legitimate answer, and that it should come with a reason.

## Unacceptable behaviour

Harassment, personal attacks, discriminatory language, sustained disruption,
publishing others' private information, or using this project's data to single out
individual developers for criticism.

That last one is specific to this repo and it is meant literally. CopilotScope
scores sessions, not people, and using it to build a case against a colleague is
against the spirit of the project regardless of what the numbers say.

## Scope

Applies to issues, pull requests, discussions and any space where someone is
representing the project.

## Enforcement

Report to the maintainer at <konradcinkusz@gmail.com>. Reports are handled
privately. Responses range from a warning to a permanent ban, depending on
severity and repetition.

Adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/),
shortened deliberately — a policy nobody reads protects nobody.
